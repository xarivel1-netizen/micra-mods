# Micra — репозиторий модов

Эталонный набор модов для сервера. Лаунчер друзей тянет моды отсюда автоматически.

## Как добавить или убрать мод

1. Кинь `.jar` в папку `mods/` (или удали ненужный).
2. Закоммить и запушь:
   ```bash
   git add mods/
   git commit -m "add sodium"
   git push
   ```
3. GitHub Action сам пересоберёт `mods/manifest.json` (список с хешами).
4. Друзья жмут **ИГРАТЬ** — лаунчер докачает новые моды и удалит убранные.

> Личные моды друга (миникарта, шейдеры и т.п.), которых нет в этом репо,
> лаунчер **не трогает** — обновление их не удалит.

## Файлы

| Файл | Что это |
|------|---------|
| `pack.json` | версия Minecraft, версия NeoForge, IP сервера |
| `mods/*.jar` | сами моды |
| `mods/manifest.json` | авто-список (руками не редактируй) |

## pack.json

```json
{
  "name": "Micra SMP",
  "mcVersion": "1.21.1",
  "neoforgeVersion": "latest",
  "serverIp": "123.45.67.89",
  "serverPort": 25565
}
```

- `neoforgeVersion: "latest"` — брать свежую сборку линии `21.1.x`. Можно вписать точную, напр. `"21.1.248"`.
- `serverIp` — если указать, в лаунчере работает галка «сразу зайти на сервер». Не нужен — поставь `null`.

## Локально пересобрать манифест (необязательно)

```bash
node scripts/gen-manifest.js
```
